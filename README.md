### 👁️ Основная деятельность: OSINT & Расследования

Мой главный фокус и профиль работы — **OSINT (Open Source Intelligence)**: поиск, сбор, верификация данных и расследование цифровых следов в публичных, полузакрытых источниках и утечках данных.

```bash
# Текущие векторы исследований:
$ target --analyze GEOINT   # Спутниковый анализ, триангуляция, тени, архитектурные маркеры
$ target --analyze SOCMINT  # Деанонимизация профилей, восстановление связей, цифровой след
$ target --analyze METADATA # Извлечение артефактов из файлов, фото/видео, EXIF, временные метки
$ target --analyze THREAT   # Мониторинг утечек баз данных, анализ инфраструктуры и доменов
```

### 💻 Программирование как хобби & пет-проекты

> *Разработка для меня — это прикладное хобби: я пишу софт для решения нестандартных задач, автоматизации рутины поиска и создания автономных утилит.*

#### 📁 Проекты:

* **[on-the-go](https://github.com/Fluxess/on-the-go)** — *Android, Kotlin, Jetpack Compose, Room, FusedLocation*  
  Автономный мобильный GPS-будильник и трекер точек для поездок. Полный приоритет приватности: данные точек и геолокация обрабатываются исключительно локально на устройстве (Zero-telemetry leak). Опубликован в каталоге [RuStore](https://www.rustore.ru/catalog/app/ru.routealert.app).

* **osint-recon-scripts** — *Python, Playwright, BeautifulSoup4, Asyncio*  
  Набор кастомных модулей и скриптов для быстрой автоматизации сбора информации по никнеймам, номерам, доменам и метаданным.

* **data-leak-parser** — *Python, Bash, Regular Expressions*  
  Утилита для быстрой нормализации, очистки и поиска по неструктурированным дампам баз данных.
